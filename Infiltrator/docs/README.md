## 🔗 Быстрые ссылки

### Основные команды
```bash
# Базовый анализ
python3 infiltrator_v2.py bundle.js

# Расширенный анализ
python3 infiltrator_v2.py bundle.js --stealth -o results.json

# Помощь
python3 infiltrator_v2.py --help
```

### Конфигурация
```python
from infiltrator_v2 import InfiltratorV2, InfiltratorConfig

config = InfiltratorConfig(enable_stealth=True)
infiltrator = InfiltratorV2(config)
results = infiltrator.analyze_bundle("bundle.js")
```

### Пример результатов
```json
{
  "endpoints": [...],
  "process_env_vars": [...],
  "risk_assessment": {...}
}
```
