## 🚨 Важные изменения (Breaking Changes)

### v2.0.0
- **Новый формат результатов**: Структура JSON результатов полностью изменена
- **Новая система конфигурации**: `InfiltratorConfig` заменяет старые параметры
- **Измененный API**: Все методы программного интерфейса обновлены
- **Новые зависимости**: Требуется Python 3.7+

### Миграция с v1.x на v2.0
```python
# Старый синтаксис (v1.x)
results = infiltrator.analyze("file.js", options)

# Новый синтаксис (v2.0)
config = InfiltratorConfig(enable_stealth=True)
infiltrator = InfiltratorV2(config)
results = infiltrator.analyze_bundle("file.js")
```

## 📝 Примечания

### Версионирование
INFILTRATOR следует [Semantic Versioning](https://semver.org/lang/ru/):
- **MAJOR**: Обратно несовместимые изменения
- **MINOR**: Новые функции, обратно совместимые
- **PATCH**: Исправления ошибок, обратно совместимые

### Частота релизов
- **Major**: каждые 6-12 месяцев
- **Minor**: каждые 2-3 месяца  
- **Patch**: по необходимости

### Качество
- Все релизы проходят автоматическое тестирование
- Ручное тестирование на реальных проектах
- Аудит безопасности перед major релизами
