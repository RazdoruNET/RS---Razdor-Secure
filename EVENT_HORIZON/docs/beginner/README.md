# EVENT HORIZON - Руководство для начинающих

## 🎯 Что такое EVENT HORIZON?

EVENT HORIZON - это инструмент для тестирования безопасности веб-приложений. Он помогает найти уязвимости в системах аутентификации и проверить, насколько хорошо защищено приложение.

## 🚀 Быстрый старт

### Что вам нужно:
- Python 3.11 или новее
- Docker и Docker Compose
- Базовые знания командной строки

### Установка (5 минут):

```bash
# 1. Клонируйте репозиторий
git clone <repository-url>
cd windsurf-project

# 2. Установите зависимости
pip install -r requirements.txt

# 3. Запустите изолированную лабораторию
./start-isolated-lab.sh
```

### Первый тест (2 минуты):

```bash
# Запустите базовый тест против mock-сервиса
python -m src.main --target http://mock-target:9000
```

## 📊 Что делает EVENT HORIZON?

EVENT HORIZON выполняет следующие типы тестов:

### 1. Тестирование аутентификации
- Проверяет устойчивость системы к попыткам входа
- Тестирует разные методы аутентификации
- Ищет слабые места в механизмах входа

### 2. Проверка ограничений скорости (Rate Limiting)
- Тестирует, насколько хорошо работает ограничение запросов
- Пытается обойти защиту
- Проверяет устойчивость к всплескам трафика

### 3. Тестирование нормализации входных данных
- Проверяет, как система обрабатывает разные варианты входов
- Ищет несоответствия в обработке данных
- Тестирует кодировки и специальные символы

### 4. Анализ заголовков HTTP
- Генерирует разные комбинации заголовков
- Проверяет корректность обработки
- Ищет проблемы в парсерах

## 🔧 Основные команды

### Запуск в изолированной среде:
```bash
python -m src.main --target http://mock-target:9000
```

### Проверка изоляции:
```bash
python -m src.main --validate-isolation --target http://localhost:9000
```

### Запуск со сценарием:
```bash
python -m src.main --target http://mock-target:9000 --scenario scenarios/basic_auth_test.yaml
```

## 🎓 Понимание результатов

### Что означают результаты тестов:

**Успешный тест** - система справилась с нагрузкой без проблем
**Предупреждение** - обнаружены потенциальные проблемы
**Ошибка** - критическая проблема безопасности

### Где смотреть результаты:

- **Логи** - `logs/` директория
- **Отчёты** - `data/` директория
- **Grafana** - http://localhost:3000 (визуализация)

## ⚠️ Важные правила безопасности

### ✅ РАЗРЕШЕНО:
- Тестировать в изолированной лаборатории
- Использовать mock-сервисы
- Тестировать с официальным разрешением

### ❌ ЗАПРЕЩЕНО:
- Тестировать реальные сайты без разрешения
- Использовать для атак
- Превышать лимиты запросов

## 🔍 Поиск проблем

### Если что-то не работает:

1. **Проверьте Docker**
```bash
docker --version
docker-compose --version
```

2. **Проверьте Python**
```bash
python --version  # Должен быть 3.11+
```

3. **Проверьте порты**
```bash
# Убедитесь, что порты не заняты
lsof -i :8000
lsof -i :9000
```

4. **Посмотрите логи**
```bash
docker-compose -f docker-compose-isolated.yml logs
```
