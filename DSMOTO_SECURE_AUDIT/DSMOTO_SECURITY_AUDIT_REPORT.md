## 4. Анализ Модели Угроз

### 4.1 Угрозы высокого риска

#### Кибернетические угрозы
1. **Уязвимости веб-приложений**
   - Устаревшая версия PHP на основном e-commerce сайте
   - Потенциальные SQL-инъекции, XSS уязвимости
   - Риск: Утечка данных, финансовые потери

2. **Безопасность доменов**
   - WHOIS защита конфиденциальности не включена
   - Риск: Угон домена, социальная инженерия

#### Угрозы непрерывности бизнеса
1. **Единая точка отказа**
   - Зависимость от устаревшего PHP приложения
   - Риск: Нарушение обслуживания, потеря доходов

2. **Риски цепочки поставок**
   - Управление запасами запчастей
   - Риск: Контрафактные запчасти, ущерб репутации

### 4.2 Угрозы среднего риска

#### Операционная безопасность
1. **Физическая безопасность**
   - Местоположение сервисного центра раскрыто публично
   - Риск: Кража, вандализм

2. **Информационная безопасность**
   - Процедуры обработки данных клиентов неясны
   - Риск: Нарушение конфиденциальности, регуляторные штрафы

### 4.3 Рекомендации по смягчению рисков

#### Немедленные действия (0-30 дней)
1. **Обновить версию PHP** на dsmoto.ru до последней стабильной версии
2. **Включить защиту конфиденциальности WHOIS** для обоих доменов
3. **Внедрить Web Application Firewall** (WAF)
4. **Провести аудит безопасности** веб-приложений

#### Краткосрочные действия (30-90 дней)
1. **Мигрировать на кодировку UTF-8**
2. **Внедрить мониторинг SSL сертификатов**
3. **Создать план реагирования на инциденты**
4. **Обучить персонал осведомленности о безопасности**

#### Долгосрочные действия (90+ дней)
1. **Разработать современную e-commerce платформу**
2. **Внедрить комплексную стратегию резервного копирования**
3. **Создать систему мониторинга безопасности**
4. **Регулярное пентестирование**
