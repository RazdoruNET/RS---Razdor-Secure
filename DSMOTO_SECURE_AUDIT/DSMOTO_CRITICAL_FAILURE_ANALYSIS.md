## 6. ПЛАН НЕМЕДЛЕННОГО УСТРАНЕНИЯ

### 6.1 Экстренные действия (0-24 часа)

#### 1. Блокировка атак SQL-инъекций
```bash
# Внедрить правила WAF
SecRule ARGS "@detectSQLi" \
    "id:1001,\
    phase:2,\
    block,\
    msg:'SQL Injection Attack Detected',\
    logdata:'Matched Data: %{MATCHED_VAR} found within %{MATCHED_VAR_NAME}'"
```

#### 2. Временная защита
- Внедрить валидацию ввода
- Добавить параметризованные запросы
- Включить подавление сообщений об ошибках

### 6.2 Критические исправления (1-7 дней)

#### 1. Обновление версии PHP
```bash
# Цель: PHP 8.2+
# Действия:
- Резервное копирование текущей системы
- Обновление зависимостей
- Тестирование совместимости
- Первоначальное развертывание на тестовом сервере
```

#### 2. Исправление SQL-инъекций
```php
// До (уязвимо):
$query = "SELECT * FROM products WHERE id = " . $_GET['id'];

// После (безопасно):
$stmt = $pdo->prepare("SELECT * FROM products WHERE id = ?");
$stmt->execute([$_GET['id']]);
```

### 6.3 Укрепление безопасности (1-30 дней)

#### 1. Внедрить заголовки безопасности
```nginx
add_header X-Frame-Options DENY;
add_header X-Content-Type-Options nosniff;
add_header X-XSS-Protection "1; mode=block";
add_header Strict-Transport-Security "max-age=31536000";
```

#### 2. Включить только HTTPS
```nginx
server {
    listen 80;
    server_name dsmoto.ru mydsmoto.ru;
    return 301 https://$server_name$request_uri;
}
```
