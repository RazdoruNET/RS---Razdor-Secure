**Дата анализа:** 7 мая 2026 г.

## ИСПОЛНИТЕЛЬНАЯ СВОДКА

Проведен углубленный анализ внешних интеграций платформы uCoz. Обнаружены критические уязвимости в системе внешних зависимостей, требующие немедленного вмешательства.

### Обнаруженные угрозы:
- **КРИТИЧЕСКИЙ:** Потенциальная возможность перехвата домена mc.yandex.ru
- **ВЫСОКИЙ:** WHOIS данные раскрывают контактную информацию технической поддержки
- **СРЕДНИЙ:** Отсутствие проверки форм обратной связи на инъекции

### 🎯 КРИТИЧЕСКАЯ НАХОДКА:

#### Yandex.Metrika Widget
```
URL: https://mc.yandex.ru/metrika/watch.js
Домен: mc.yandex.ru
Статус: НЕВОЗМОЖНО ОПРЕДЕЛИТЬ ДАТУ ИСТЕЧЕНИЯ
```

**Анализ рисков:**
- **Уровень угрозы:** КРИТИЧЕСКИЙ
- **Вектор атаки:** Если домен mc.yandex.ru станет доступен для регистрации
- **Последствия:** Полная компрометация сайта через вредоносный скрипт

**Сценарий атаки:**
1. Домен mc.yandex.ru истекает или становится доступным
2. Злоумышленник регистрирует домен
3. Размещает вредоносный JavaScript код
4. Все посетители dsmoto.ru загружают вредоносный код
5. Возможна кража сессий, учетных данных, установка бэкдоров

```

3. Размещение вредоносного скрипта

```

### 📧 Вторичный вектор - Social Engineering:
```
1. Использование WHOIS контактов
2. Фишинг через ru-tech@tcinet.ru
3. Имперсонация технической поддержки
4. Получение учетных данных администратора
```

### 🔐 Третичный вектор - Admin Panel Brute Force:
```
1. Направление на /admin/
2. Перебор учетных данных

4. Получение доступа к управлению сайтом
```
